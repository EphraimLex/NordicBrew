
# Nordic Brew - Project Plan

## 1. Project Overview

Nordic Brew is a fictional modern coffee shop.

The project is a responsive single-page business website built
with HTML, CSS, and JavaScript.

The aim is to practise frontend development while creating
a simple, professional, and user-friendly website.

## 2. Business and Target Customers

- Business name: Nordic Brew
- Business type: Modern coffee shop
- Products: Coffee, tea, pastries, and light sandwiches
- Atmosphere: Warm, welcoming, and comfortable

Target customers:
- Local residents
- Students
- People looking for a place to meet friends or work

## 3. Website Goals

The website should help visitors:
- Learn about the coffee shop.
- Explore the menu and prices.
- See images of the café and its products.
- Find opening hours and contact details.

The website will clearly identify the business as fictional.

## 4. Page Structure

The website will contain the following sections:

### Header and Navigation
- Business name
- Links to Home, About, Menu, Gallery, and Contact

### Home
- Main heading and short introduction
- A welcoming café image
- A "View our menu" link leading to the Menu section

### About
- A short introduction to Nordic Brew
- A description of the café's atmosphere and values

### Menu
- Drinks and food with descriptions and prices
- Filter buttons: All, Drinks, and Food

### Gallery
- Images of the café, drinks, and food

### Contact
- Example location and contact details
- Opening hours
- A clear note that this is a fictional business

### Footer
- Business name
- Copyright information
- Educational project note

## 5. Design Direction

The website will have a warm, welcoming, and simple appearance.

### Colors
- Page background: Warm cream (#F7F3EC)
- Main text: Dark brown (#332820)
- Buttons and links: Dark muted green (#365544)
- Cards: White (#FFFFFF)
- Subtle borders: Light beige (#DDD4C7)

### Typography
- Headings: Georgia, serif
- Body text and navigation: Arial, sans-serif
- Base font size: 16px
- Body line height: 1.6

### Layout
- Centered content with a maximum width of 1100px
- Consistent spacing between sections
- Simple cards for menu items
- Three-column menu and gallery on desktop
- Two columns on tablet
- One column on mobile
- Navigation links wrap on smaller screens

### Wireframes
Desktop and mobile wireframes are saved in:
docs/NordicBrew_Wireframes.pptx

## 6. Technologies

- HTML5 for content and semantic structure
- CSS3 for styling
- CSS Grid and Flexbox for layouts
- Media queries for responsive design
- JavaScript for menu filtering
- Git and GitHub for version control
- GitHub Pages for deployment

CSS and JavaScript will be stored in separate external files.

Bootstrap and Tailwind will not be used in this project.

## 7. JavaScript Interaction

Visitors will be able to filter menu items using:
- All: Show every item
- Drinks: Show only drinks
- Food: Show only food

The selected filter will be clearly indicated.

All menu items should remain visible if JavaScript is unavailable.

## 8. Responsive Design and Accessibility

The website should work on desktop, tablet, and mobile.

We will:
- Use flexible layouts and responsive images.
- Stack content where necessary on smaller screens.
- Keep navigation usable on narrow screens.
- Use semantic HTML and a logical heading structure.
- Add meaningful alternative text to informative images.
- Use sufficient color contrast.
- Make links and buttons usable with a keyboard.
- Provide visible keyboard focus indicators.

## 9. File Organization

- index.html: Website structure and content
- css/style.css: Styling and responsive layouts
- js/script.js: Menu filtering
- images/: Website images
- README.md: Project overview and running instructions
- docs/planning.md: Project plan
- docs/: Wireframes and presentation slides

## 10. Implementation Steps

1. Define the business and website goals.
2. Complete the initial project plan.
3. Create desktop and mobile wireframes.
4. Choose colors, typography, and images.
5. Build the HTML structure.
6. Add CSS styling and responsive layouts.
7. Implement JavaScript menu filtering.
8. Test the website and fix issues.
9. Publish the project on GitHub and GitHub Pages.
10. Finalize the README and presentation slides.

## 11. Testing Plan

Check that:
- Navigation links reach the correct sections.
- Menu filters display the correct items.
- The website works at desktop, tablet, and mobile widths.
- No unwanted horizontal scrolling occurs.
- Images load correctly.
- All links and buttons work.
- Interactive elements can be used with a keyboard.
- Text is readable and focus indicators are visible.
- The deployed website works correctly.

## 12. Documentation and Presentation

The README will include:
- Project description
- Features
- Technologies used
- Instructions for running the website
- Live website link
- Image credits where required

Presentation slides will cover:
- Business idea and target customers
- Website structure and wireframes
- Design choices
- HTML, CSS, and JavaScript implementation
- Responsive design and testing
- A demonstration of the finished website

No separate development log will be maintained.

## 13. Scope and Deliverables

The project will remain a small frontend website.

Online payments, real ordering, and backend functionality
are outside the scope.

Final deliverables:
- Public GitHub repository URL
- Live website URL
